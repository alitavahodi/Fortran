# Fortran Scientific Computing

A collection of Fortran programs developed for numerical methods, scientific computing, and computational physics.

This repository contains implementations of fundamental numerical algorithms and computational techniques, with an emphasis on solving mathematical and physical problems using Fortran 90/95.

---

## Topics

* Fundamental Fortran Programming
* Arrays and Matrix Operations
* Numerical Integration
* Ordinary Differential Equations
* Runge–Kutta Methods
* Taylor Methods
* Monte Carlo Methods
* Numerical Methods
* Laplace and Poisson Equations
* Potential and Field Simulations
* Computational Physics

## Numerical Methods

The repository includes implementations and exercises involving:

| Method                      | Application                           |
| --------------------------- | ------------------------------------- |
| Runge–Kutta 4th Order (RK4) | Ordinary differential equations       |
| Taylor Method               | Ordinary differential equations       |
| Trapezoidal Rule            | Numerical integration                 |
| Simpson's Rule              | Numerical integration                 |
| Monte Carlo Integration     | Single and multidimensional integrals |
| Finite-Difference Methods   | Potential and field simulations       |
| Matrix Multiplication       | Numerical linear algebra              |
| Statistical Methods         | Mean and standard deviation           |
